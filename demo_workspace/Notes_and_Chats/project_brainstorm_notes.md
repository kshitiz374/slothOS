# Project SlothOS Brainstorm & Product Roadmap

## Core Thesis
Traditional productivity apps make people feel guilty with streaks, badges, and red notification counters. 
SlothOS takes the opposite approach: embrace human laziness. Automate repetitive digital housekeeping silently and safely.

## Key Feature Checklist
- [x] Sandboxed directory organizer with zero path traversal risk
- [x] 1-Click Undo Manifest: Revert moves instantly without manual hunting
- [x] Lazy Morning Briefing: Extract top 5 highlights and deadlines from messy logs
- [x] Procrastination Crusher: Deconstruct intimidating mountains into 5-minute pebble tasks
- [x] Document Assistant: Convert rambles into neat checklists and structured markdown
- [ ] Add voice command transcription via local Whisper (Future milestone)

## Open Technical Questions
- How do we handle file locks on Windows when another application has the target file open?
- Can we benchmark Qwen 2.5 vs Mistral 7B inference latency on CPU-only machines?
